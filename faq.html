Common questions

Use the questions below to quickly understand how the current TechStore website works.

Start with your main use, then compare the processor, RAM, storage, display, graphics, battery needs and portability. Our Laptop Buying Guide explains these choices in simple terms.

RAM is short-term working memory used while programs are running. Storage keeps files, applications and the operating system for longer-term use. See the RAM Guide for more detail.

An SSD is a solid-state storage device. It has no moving mechanical parts and is commonly chosen for fast everyday storage. Compare it with an HDD in our SSD vs HDD guide.

It can be, depending on the student's workload and priorities. Gaming laptops can offer strong hardware, but students should also consider weight, battery expectations, cost and portability. See the Student Laptop Guide and Gaming Laptop Guide.

Use the Compare option available in the TechStore header and product interface. The existing compare feature lets you place products into the comparison view.

Use the wishlist button on supported product cards. Your current project stores wishlist items in LocalStorage, so the wishlist can be viewed from the Wishlist page.

Add products with the cart controls, then open the Cart to review selected items before checkout. The current project keeps cart data in LocalStorage.

During checkout, enter a supported coupon code. The current demo includes TECH10, SAVE500 and WELCOME5, each with its own minimum-order and discount rules. The selected coupon is stored by the existing LocalStorage system.

The checkout currently offers Cash on Delivery and Demo Card Payment. Demo Card Payment does not process a real transaction; this is a front-end project rather than a live payment gateway.

Open My Orders after signing in. The current project provides order history and order details for the signed-in user.

The existing order system supports cancellation when an order meets the cancellation rules implemented in the project. Open the order from My Orders to see whether cancellation is available.

The current checkout logic charges ₹99 when the subtotal is below ₹50,000 and free delivery when the subtotal is ₹50,000 or more. The checkout summary shows the amount before an order is created.
